# 微信公众平台「填写小程序信息」四项内容汇总

> 项目：Q 版排球（微信小游戏，three.js，2v2 人机 + 好友组队）
> 字符统计规则与公众平台一致：中文/全角 = 2 字符，英文/数字 = 1 字符。
> 以下所有字符数为脚本实测（`.tmp-avatar/verify.py` 同款逻辑：`sum(2 if ord(c)>127 else 1)`），非人工估算。

---

## 1. 小程序名称（规则：4–30 字符）

### 主推荐（直接复制）

```text
Q版排球大作战
```

- 实测字符数：**13 字符**（Q=1 + 版/排/球/大/作/战 各2），限额 4–30，余量充足
- 推荐理由：
  - 保留「排球」核心词，用户搜"排球"时能命中；但不是裸的"排球"，前面有「Q版」锁定画风、后面有「大作战」锁定游戏类型，和一堆泛"排球"工具/资讯号能明显区分开
  - 与游戏内标题「Q版排球」同源，首页 logo 和小游戏名互相印证，品牌一致
  - 全部为通用词组合，不含他人商标与知名 IP（已刻意避开"排球少年""排球女将"等字样）
- 关于"排球太通用"的处理思路：不单独用「排球」做名字，而是"修饰词 + 排球 + 品牌后缀"的三段组合，检索有辨识度、品牌有记忆点

### 备选

| 备选名称 | 实测字符数 | 理由 / 代价 |
|---|---|---|
| `Q版排球` | 7 字符 | 与游戏内 logo 完全一致，最短最好记；代价是组合较常见，若注册时提示重名，换主推荐 |
| `Q弹排球`  | 7 字符 | "Q弹"双关（Q版画风 + 果冻感人物手感），自带网感；代价是弱化"对战"信息 |
| `排球小斗士` | 10 字符 | 突出角色感和休闲竞技；代价是"斗士"比实际画风偏硬，与轻松调性略有出入 |

## 2. 小程序简称（规则：4–10 字符，且必须能从名称中按顺序选取字符）

以下两个方案均取自主推荐「Q版排球大作战」，满足"顺序选取"：

### 方案一（直接复制）

```text
Q版排球
```

- 取自名称第 1–4 字：**Q → 版 → 排 → 球**，严格按原顺序，实测 **7 字符**

### 方案二

```text
排球大作战
```

- 取自名称第 3–7 字：**排 → 球 → 大 → 作 → 战**，严格按原顺序，实测 **10 字符**（正好顶满限额）

## 4. 小程序介绍（规则：≤120 字符）

### 版本 A：玩法卖点（实测 102 字符 = 49 汉字×2 + 4 个 ASCII×1）

```text
Q版卡通画风的2v2排球对决，蓄力发球、起跳拦网、大力扣杀，三局两胜节奏快，上手简单，碎片时间随时开一局。
```

### 版本 B：社交卖点（实测 106 字符 = 51 汉字×2 + 4 个 ASCII×1）

```text
邀请微信好友组队，2人搭档挑战两名AI球员，跑位传接、拦网扣杀，赢下三局两胜的Q版排球赛，发房间码就能一起打。
```

两版均为平铺直叙的白话，无"最/第一/极致"等极限词，无夸大宣传，符合平台审核口径。

## 5. 提交注意事项

- **名称、简称是四项里改动成本最高的**：提交后如需修改要走账号改名流程且次数受限，还可能因重名被驳回，建议提交前从上面备选里一次定稿
- **头像和介绍也并非随时可随意改**（平台按月限制修改次数），建议本页四项一次定稿后再提交
- 名称若提示与已有帐号重复，按"主推荐 → 备选1 → 备选2"顺序顺延即可，字符数均已实测合规
- 头像上传时平台会做圆形预览，以 `avatar-preview-circle.png` 为准确认过三档尺寸均不裁切关键元素，放心上传 `avatar-144.png`
