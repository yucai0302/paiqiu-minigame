# 小游戏审核必填 · 用户隐私保护指引 + 适龄提示

> 核实范围：`minigame/src/platform/wx.ts`、`minigame/src/platform/wx-shim.ts`、`minigame/src/net/cloud.ts`、`minigame/cloudfunctions/`。本版本无内购、无广告、无道具/货币系统。

# A. 用户隐私保护指引设置

## A1. 核实结论

**属于第 ② 种：「处理了用户信息，需如实填报处理情况」。**

代码实际处理的信息只有三类：

1. **微信昵称**：`platform/wx.ts` 的 `getNickName()` 调用 `wx.getUserInfo` 读取 `userInfo.nickName`，取不到时回落为「玩家」；昵称随建房/进房写入云数据库，用于房间与对局内展示。
2. **openid**：云函数里通过 `cloud.getWXContext().OPENID` 自动获得（`createRoom` / `joinRoom` / `startMatch` / `settleMatch` / `markDisconnect`），写入 `rooms.members` 等字段，用于座位、房主写权限与断线判定。
3. **对局数据**：房间号、座位、比分/局数、球员位置输入、快照等，存于 `rooms`、`rooms_live`、`rooms_inputs`，只在同一房间两名成员之间同步。

**未处理**：头像、位置、通讯录、相册、摄像头、麦克风、剪贴板、支付信息、设备标识。`wx-shim.ts` 只在本机读取窗口尺寸/像素比用于画面适配，不上传、不落库、不共享。

## A2. 填报对应表（可照抄）

| 信息类型 | 具体数据 | 用途 | 存储位置 | 是否第三方共享 |
|---|---|---|---|---|
| 用户信息 | 微信昵称（取不到时用默认「玩家」） | 好友组队房间座位显示、对局内昵称展示 | 微信云开发数据库 `rooms.names`、`matchCfg.names` | 否 |
| 用户标识 | openid（微信平台分配） | 区分房间座位、校验房主写入权限、判定断线与重连 | 云数据库 `rooms.members`、`rooms_live.members`、`rooms_inputs.members` | 否 |
| 用户操作/对局数据 | 房间号、比分、局数、球员位置输入、对局快照 | 双人联机对局实时同步 | 云数据库 `rooms`、`rooms_live`、`rooms_inputs` | 否 |
| 设备信息 | 无（仅本机读取屏幕尺寸/像素比做适配，不上传） | 画面渲染适配 | 不存储 | 否 |
| 头像 / 位置 / 相册 / 通讯录 / 麦克风 / 摄像头 | 未收集 | — | — | — |

## A3. 是否需要隐私弹窗

**需要。** 依据：

- **openid** 由云函数 `getWXContext()` 直接获得，不触发用户授权，单它本身不需要弹窗。
- **昵称**走 `wx.getUserInfo`，属于需要隐私授权的接口。因此必须：
  1. 在公众平台「设置 → 服务内容声明 → 用户隐私保护指引」中勾选「用户信息」，说明中写明**仅获取微信昵称，不获取头像**；
  2. 小游戏内先 `wx.getPrivacySetting` 查询 `needAuthorization`，需要时通过 `wx.requirePrivacyAuthorize`（或监听 `wx.onNeedPrivacyAuthorization` 弹官方/自研隐私弹窗）让用户同意后，再调用 `wx.getUserInfo`；
  3. 用户拒绝时保持默认昵称「玩家」，联机功能照常可用。
- 代码**没有**调用 `wx.getUserProfile`、`wx.chooseAvatar`、`wx.getLocation`、`wx.chooseMedia`，所以隐私指引里不要勾位置、相册、摄像头、麦克风等项目。
- 如果不想做昵称弹窗，可以删除 `wx.getUserInfo` 调用、固定用「玩家」；但因仍会存 openid 和对局数据，**依然属于第 ② 种**，不能选「未处理任何信息」，只是无需再为昵称做授权弹窗。

## A4. 处理情况说明（可直接粘贴）

```text
本游戏仅在微信好友组队模式下处理必要信息。通过微信云开发云函数获取用户 openid，仅用于区分房间座位、校验房主写入权限及判定断线重连，不用于其他用途。通过 wx.getUserInfo 获取微信昵称，仅用于好友组队房间和对局内的昵称展示；用户未授权或获取失败时使用默认昵称「玩家」。对局过程中产生的房间号、比分、局数、球员位置输入与对局快照存放于微信云开发数据库，仅本房间两名成员可读写。以上信息不向任何第三方共享，不用于广告投放或用户画像。本游戏未收集头像、位置、通讯录、相册、麦克风、摄像头及设备标识信息，未开通虚拟支付。
```

字数：**265 字符**（按字符计，含标点；该字段无上限）。

# 提交提醒

- 隐私指引按第 ② 种填报，勾选「用户信息」，说明里强调**只取昵称、不取头像**；openid 与对局数据写入「处理情况说明」。
- 昵称弹窗与隐私指引要先配置好再提审：后台指引未配置时，`wx.getUserInfo` 可能拿不到昵称，审核也可能因「未声明即处理」驳回。
- 适龄提示按 **8+ / 休闲 / 无内购 / 单人模式 / 无陌生人社交** 填；若审核要求与主推玩法一致，单人模式就是主按钮入口，依据充分。
